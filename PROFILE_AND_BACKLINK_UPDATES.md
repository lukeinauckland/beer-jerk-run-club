# Profile And Backlink Updates

Use these to keep the club's time, location and official link consistent everywhere.

## Priority Order

1. NZ Running listing: correct the time to 5:40pm and keep the official website link.
2. Beer Jerk About or Run Club page: correct the time and add a visible official website link.
3. Small Gods Taproom page: remove the 5:15pm and 5:30pm references, replace them with the exact current wording, and add the official website link.
4. Instagram: use the current time and official website as the profile link.
5. Strava: use the current time and official website near the top of the club description.
6. Meetup: correct the displayed event time and retain the official website link in the description.
7. Paul Huxen case study: ask for the current time and official website link.
8. Auckland editorial roundups: pitch the club for inclusion after the listings above are consistent.

## Exact Details To Use Everywhere

```text
Beer Jerk Run Club is a free Auckland run club with a weekly social 5km.

Mondays at Small Gods Taproom, 2 Shaddock Street, Eden Terrace.
Bag drop from 5pm. Run starts 5:40pm sharp.
Free. No signup. Just turn up.

Current schedule, routes and first-timer information:
https://beerjerkrunclub.co.nz
```

Do not publish 5:15pm or 5:30pm as the start time.
